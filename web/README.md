# 全栈之旅 · Web 互动课程平台(阶段 0~3 · 12 章)

形式对齐 llm-journey 的 web 平台:**每章只加一个机制 × 阅读/模拟器双视图**,全部离线运行,进度存本机浏览器。

## 打开方式

```bash
cd web
npm install
npm run dev        # http://localhost:5180(固定端口,避免和 llm-journey 的 5173 撞车)
npm run build      # 生产构建 → dist/(gzip 约 73KB,可静态托管)
```

## 每章的正确打开顺序

1. 先玩**模拟器**(5 分钟,建立直觉,猜输出错题不丢人);
2. 再读**阅读视图**(四问 → 机制 → 对暗号 → 发散问题 → 🤔 → 🏛 权威佐证);
3. 做**预测题**(先写预测再揭示;错题去场次里用实验卡追根因);
4. 去对应阶段的手册动手(如 `phase0-ts-async/AI助学手册.md` 的 S1、`phase3-data-net/AI助学手册.md` 的 S27)——**模拟器是预演,落库才算完成**。

> 🧰 路上遇到紫色的**"发散补充盒"**(可折叠),是没有 TS/JS/HTML/CSS 基础时的就地补课——首次出现的概念都在里面,用 Java/CS 对应物锚定;有基础可以跳过。
