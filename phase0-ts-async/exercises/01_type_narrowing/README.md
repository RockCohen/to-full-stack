## 怎么做

1. 把实验卡的代码(或你自己的变体)贴进本目录 `playground.ts`;
2. 运行类:`pnpm lab phase0-ts-async/exercises/01_type_narrowing/playground.ts`
3. 编译类:`pnpm tscf phase0-ts-async/exercises/01_type_narrowing/playground.ts`
4. E8 的重写成果也放本目录(如 `state-machine.ts`),让 AI 用 ⑤ 卡 review。
