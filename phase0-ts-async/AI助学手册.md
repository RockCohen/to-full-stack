## 每场操作单

### S1 · 类型:血统 vs 体检报告(2.5h)
- 开场:贴 ⓪ 契约 → ① 摸底卡(主题:TS 类型系统)。
- **先猜再读**:翻开 [`MAP.md`](MAP.md) §1 之前,先自己回答"TS 的 interface 和 Java 的 interface 像吗?哪里像?"——把猜测记进笔记,读完对照。
- 做 [`tutor/experiments_s1_类型与收窄.md`](tutor/experiments_s1_类型与收窄.md):每题**先写预测**再验证。运行类用 `pnpm lab <文件>`,编译类用 `pnpm tscf <文件>`。答错 → ② 卡出 2 道同款变体,直到连对。
- 收尾三件套:整理 playground → `exercises/01_type_narrowing/`,commit,情式笔记。

### S2 · 泛型与工具类型(2h)
- ① 摸底(主题:泛型)。做 [`tutor/experiments_s2_泛型与工具类型.md`](tutor/experiments_s2_泛型与工具类型.md),重点盯 E3/E4——DTO 投影与 PATCH 语义你在 Spring 里写过一百遍,这次只是换了门语法。
- 终极实验 E5:亲手把 TS 编译产物打开,亲眼确认 `number` 蒸发了。
- 一句话验收(讲给 AI 听):**"TS 为什么需要 zod?"** 答不上一句的,回读 MAP §1.4。
- 转场语(记进笔记):类型是编译期的法律,运行时没警察。下一场,我们去看看运行时的"派出所"——事件循环。

### S3 · 事件循环:单线程的调度艺术(2.5h)
- ① 摸底:让 AI 直接出 3 道输出顺序题,先体验"猜错"的感觉。
- 做 [`tutor/experiments_s3_事件循环.md`](tutor/experiments_s3_事件循环.md) 全部 7 题。注意 E2 会**挂住进程**,观察完 Ctrl+C 逃逸——这不是事故,是教材。
- 终极验收:合上所有材料,口头向 AI 讲清"await 到底做了什么",全程**用"让出"造句,不许出现"等待/阻塞"**。讲歪了它会追问。
- 转场语:你已经用了一周别人写的微任务队列——接下来两场,把这个队列和它服务的 Promise,亲手造出来。

### S4 · ⛔禁写区·MyPromise Ⅰ(2.5h)
- 开工仪式:③ 禁写区开工卡 + 读 [`exercises/04_my_promise/README.md`](exercises/04_my_promise/README.md)。
- 路线(只做前三步):**状态机设计 → 构造函数与 executor → then 的异步保证(queueMicrotask)**。
- 纪律:方法签名就是契约,不许改;不看原生 Promise 源码;卡壳 30 分钟才准用 ④ 卡,且只要线索不要答案。
- 完成标志:`pnpm lab:promise` 中 01~05、13、20 号用例绿(其余红是常态,别慌)。

### S5 · ⛔禁写区·MyPromise Ⅱ(2.5h)
- 路线(后三步):**链式与值平化 → 错误传播与"修复" → all/race**。
- 完成标志:`pnpm lab:promise` **21 例全绿**。
- 用 ⑤ 答辩考官卡 review 你的实现:它只找概念性误解,会就疑点连环追问。
- 转场语:恭喜,你刚造完了前端世界的 CompletableFuture 内核——下一步,让 AI 拿着题库来验货。

### S6 · 双答辩 + 补漏(1.5h)
- 把 [`tutor/defense_TS类型系统_10问.md`](tutor/defense_TS类型系统_10问.md) 与 [`tutor/defense_事件循环_10问.md`](tutor/defense_事件循环_10问.md) 先后发给 AI,逐题答,它逐题追问,直到你独立讲清。
- 通过线:**两套各 ≥8 题**。答错的 → 误解记录本 → 针对性小实验修补 → 让 AI 出变体题复测。
- 可选回马枪:此刻回读 [`MAP.md`](MAP.md),你会发现 20 分钟过完全文,而且句句都能举出自己的例子——这就是"先建构、后字典"。

### S7 · 坏代码门诊(2.5h)
- 材料:[`tutor/bug_clinic/`](tutor/bug_clinic/),5 个可运行脚本,各藏 1 处 bug,症状互不相同。
- 流程(每例):运行观察症状 → **写下诊断假设** → 改最小一处验证 → 修复 → 对 [`ANSWERS.md`](tutor/bug_clinic/ANSWERS.md) 复核。
- 每例产三行笔记:症状 / 根因 / 后端对照(它像你后端生涯里的哪次事故)。
- 规则:ANSWERS 只许复核用;卡住用 ⑥ 卡要"线索",不是答案。

### S8 · 脱稿验收 + 毕业(2h)
- 不查任何资料,1 小时完成 [`exercises/05_solo_exam/README.md`](exercises/05_solo_exam/README.md) 的 `runWithConcurrency`——手写你的"线程池 + 信号量"。
- 写完不等于结束:用 ⑤ 卡让 AI 当考官,现场出 3 道附加题(题型样例见题面),≥2 道通过。
- 总答辩:事件循环 10 问随机抽 3 道口试。
- 毕业三件事:回顾误解记录本,把全部复习题拼成一次自测;情式笔记收尾;`git tag phase0-graduate` 🎓
