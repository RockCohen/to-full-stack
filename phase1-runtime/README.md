## 五、常见卡点速查

| 现象 | 处理 |
|---|---|
| 循环里的回调全都打出最后一个值 | 经典闭包陷阱:`var` 共享一个变量,换 `let` 每轮绑定——门诊 1 号专门讲它 |
| 页面越用越卡,内存持续上涨 | 八成是监听器/定时器没清理。DevTools → Memory 面板拍堆快照对比 |
| `this` 是 undefined / 不是你想的对象 | 用箭头函数字段或 `bind`;实验卡 s10 会把四种绑定讲清 |
| 排序后源数组也变了 | `sort`/`reverse` 是原地操作,先 `[...orders]` 拷贝——门诊 4 号 |
| 对拍脚本里 `store.getState()` 拿到旧值 | 检查你是不是原地修改了状态——响应式的根基是"整体替换＋引用对比" |
