# 答辩 · 闭包与内存 10 问

> 用法:整个文件发给 AI,逐题作答,它逐题追问。通过线 **≥8**。
> 纪律:讲闭包必须出现"寿命/逃逸/堆"三个词中的至少两个;讲 GC 必须出现"可达性"。

1. 用自己的话定义闭包。捕获的是值还是变量?各举一例。
2. 三次调用 makeCounter 得到三个计数器,与三次调用同一个计数器,内存上的差别是什么?
3. var 和 let 在循环闭包里的差别,根源是"作用域"还是"每次迭代的变量绑定"?讲清两者都动了什么。
4. 闭包和内存泄漏是什么关系?构成泄漏需要哪两个条件同时成立?
5. GC 如何判定对象该回收?"还有引用"和"还够得着"的差别在哪?举例说明"有引用但已是垃圾"。
6. V8 的分代回收:新生代和老生代各自用什么算法?为什么分两代?(对照 JVM 分代收集)
7. 函数在 JS 里是什么?它被抓进闭包时,堆上多出来的"环境"里存了什么?
8. 箭头函数的 this 与普通函数的 this,机制差别是什么?分别 ≈ Java 里的什么?
9. WeakMap/WeakRef 的"弱"弱在哪?用它缓存为什么不容易泄漏?(答不出可查后口述——这是 S15 后的自学加分项)
10. **综合题**:面试官说"闭包会内存泄漏",这句话哪里对、哪里错?给出更准确的表述。
