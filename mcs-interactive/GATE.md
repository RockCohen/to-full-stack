# 数学之旅 · 质量门禁（GATE）

> 这份文件存在的原因：ch01 用了 11 个装置 + 2 段 Manim 精作，后续章节在批量生产中缩水到 3~5 个装置，
> 大量原书小节只用文字带过、习题只列不做。为杜绝"覆盖 ≠ 完成"，立此门禁：
> **每章必须逐条达标才可标记为完成；不达标即"补强中"。**

## 七条门禁

| # | 门禁 | 标准 |
|---|---|---|
| G1 | 小节覆盖 | 原书每个编号小节至少由一个装置直接承载；确无互动价值的小节须并入相邻装置并在描述中声明 |
| G2 | 数量下限 | 每章互动装置 ≥ 6 个（短章 ≥ 5），基准为 ch01 的 11 个 |
| G3 | 习题落地 | 每章 ≥ 2 道原书习题做成可玩装置或可核查的解题器（Practice Problems 优先） |
| G4 | 数学正确性 | 每个数值装置有理论对拍：精确公式 / 蒙特卡洛 / 双解法交叉验证 |
| G5 | 工程质量 | console 零报错、移动端（390px）零横向溢出、file:// 直接可玩 |
| G6 | 叙事顺序 | TOC 覆盖全部小节；装置按原书行文顺序编排，有承接说明 |
| G7 | 引用对拍 | 正文全部"定理/引理/推论/定义/习题/Figure/式/页码"引用与原书逐条对拍；装置答案键、解析、提示三方互洽不自相矛盾；课后挑战出处逐一真实（2026-09-12 全书审计后新增，缘起：109 处问题中 37 处为引用不符、多处答案键与自家解析矛盾） |

## 补强流程（每章一轮）

1. 重读该章未覆盖小节的原文 → 设计新装置（对齐 G1）
2. 每个新装置过 G4：理论值与模拟/精确计算对拍；全部引用与答案键过 G7
3. Playwright 全交互测试 + G5 检查 → 部署 → 线上验证
4. 在本表打勾，更新目录页与 README 的装置数
5. 全书达标后做一次"门禁复核"提交

> 执行顺序：从最不达标开始（ch11 → ch10 → ch12/13 → ch14…），跳过已达标章。
