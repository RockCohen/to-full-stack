14.1

年金：今天的百万 vs 每年的五万

The Value of an Annuity

彩票给你两个选择：今天拿 100 万，或未来 20 年每年拿 5 万。直觉说后者总数更多？货币有时间价值：利率 p = 8% 时，一年后的 10 元今天只值 10/(1+p) ≈ 9.26 元。n 年 m 元年金的真实价值 V 是一串几何和，用扰动法（S 与 xS 相减，中间大规模抵消）可推出闭式：

V = m·(1 − xⁿ) / (1 − x)，其中 x = 1/(1+p)　　无限年期：V = m(1+p)/p

代入 5 万、20 年、8%：V ≈ $530,180——"百万大奖"现值只有半百万。永不停止的版本也只有 $675,000（银行里躺着 100 万本来就每年能花 8 万到永远）。

14.1.2扰动法：自己发现闭式

Perturbation Method

对 S = 1 + x + x² + ⋯ + xⁿ：写出 xS = x + x² + ⋯ + xⁿ⁺¹，两式相减——中间所有项大规模抵消，只剩 S − xS = 1 − xⁿ⁺¹，解出 S = (1 − xⁿ⁺¹)/(1 − x)。求导一次还能得到 Σixⁱ 的闭式（定理 14.1.2）。下一章生成函数会再用这招。

14.2

幂和：Gauss 的配对与系数猜法

Sums of Powers

高斯小学生的传说：把 1+2+⋯+n 正写一遍反写一遍，相加得 n(n+1)，所以和是 n(n+1)/2。平方和用不了这招，但可以猜它是三次多项式 an³+bn²+cn+d，代 n = 0..3 解线性方程组得 a=1/3, b=1/2, c=1/6——与 14.14 式吻合。原书警告：猜出来必须回头证明（归纳或生成函数），猜错形状就全错。

14.3

积分包围：给没有闭式的和找上下界

Approximating Sums
定理 14.3.2 · 积分包围

f 弱递增时：I + f(1) ≤ S ≤ I + f(n)，其中 I = ∫₁ⁿ f(x)dx（把和看成矩形面积、把积分看成曲线下面积）。f 弱递减时上下界对调。

例：Σ√i 被 (2/3)(n^(3/2) − 1) + 1 与 (2/3)(n^(3/2) − 1) + √n 夹住——即 S ≈ (2/3)n^(3/2)。"和 ≈ 最大项的常数倍"是几何递减/递增和的经验法则。

14.4

书堆悬挑：调和数登场

Hanging Out Over the Edge

n 本书叠成一摞、每本往桌沿外探，最多能探出多远？物理：第 i 层的质心要坐在下一层的边缘上。解递推得 Bₙ = Hₙ/2——调和数 Hₙ = 1 + 1/2 + ⋯ + 1/n 的一半！调和数没有已知闭式，但积分包围给 ln(n) + 1/n ≤ Hₙ ≤ ln(n) + 1（式 14.20）。结论：书可以悬出桌沿任意远（Hₙ ~ ln n → ∞），但代价指数级——悬出 3 本书长需要 227 本。

彩蛋与课后挑战

Easter Eggs & Problems
0.99999… = 1（原书 14.1.5，式 14.7）

0.9·Σ(1/10)ⁱ = 0.9 · 1/(1−1/10) = 1。几何级数一句顶一万句的"数学辩论终结者"。还有 1 − 1/2 + 1/4 − ⋯ = 2/3（交错级数）、1 + 2 + 4 + ⋯ + 2ⁿ⁻¹ = 2ⁿ − 1（几何递增和 ≈ 最大项的两倍）。

倒金字塔：书堆的进阶玩法（原书 14.4 末尾）

我们的"每本书只压在一本上"结论其实可以再进化：允许一本压在多本上（倒金字塔结构），n 本书能悬出 ∝ n^(1/3) 本书长——比 ln n 快得多（Maximum Overhang, [14]）。所以"调和数一半"也不是极限，是单支撑结构的极限。
