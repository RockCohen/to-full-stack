四步法：把蒙提霍尔关进树图里

The Four Step Method
The Four Step Method

① 找样本空间：树图每层一个随机量，叶子 = outcome。② 定义事件：outcome 的子集。③ 定 outcome 概率：先给每条边标概率，outcome 概率 = 路径边概率之积。④ 事件概率 = 事件内 outcome 概率求和。

蒙提霍尔：车藏在 3 扇门之一（各 1/3）→ 你初选一门（各 1/3）→ 主持人开一扇有山羊的门（有两个候选时各 1/2，只有一个时为 1）。12 个 outcome，其中"换门获胜"恰有 6 个——但 6/12 ≠ 1/2：主持人被迫开门的那些分支概率更大（1/9 vs 1/18）。逐行看树表，每行概率 = 左边三个数的乘积：

怪骰子：能打关系的塌方

Strange Dice

酒吧里三颗骰子：A = {2, 6, 7}，B = {1, 5, 9}，C = {3, 4, 8}。各掷一次比大小。四步法给出惊人的结果：

A 胜 B 概率 5/9　＞　B 胜 C 5/9　＞　C 胜 A 5/9　——非传递！

"更常获胜"不是传递关系：谁先挑骰子谁吃亏。更狠的是掷两次比总和：强弱全部反转（A vs B 从 5/9 翻成 37/81 落败）。选一颗骰子当你的，再选一颗对手的，看 9 个格子的胜负分布：

17.4

生日原则：23 人的必然

The Birthday Principle

一个班 95 人，几乎必然有两人同一天生日（概率 > 0.9999）。全部生日互不相同的概率是 ∏ᵢ (1 − i/d)（式 17.5），用 1−x ≤ e^{−x} 一夹就得到 e^{−n(n−1)/2d}。于是有计算机科学里到处出现的经验法则：

The Birthday Principle

一年 d 天，房间里约有 √(2d) 人时，两人同生日概率 ≈ 1 − 1/e ≈ 0.632。d = 365 → 约 27 人（精确 0.626；而 23 人时刚过一半，是它最出名的变体）。哈希表 n 项进 d 个桶、密码学"生日攻击"，全是同一道公式。

17.5

概率规则卡组：集合论换装登场

Set Theory and Probability
定义 17.5.1 / 17.5.2

样本空间 𝒮 是非空可数集；事件是子集；概率函数 Pr : 𝒮 → ℝ 满足 Pr[ω] ≥ 0 且 ΣPr[ω] = 1。事件概率 Pr[E] = Σ_{ω∈E} Pr[ω]。uniform 空间里 Pr[E] = |E|/|𝒮|——第 15 章的全部计数工具在这里直接变现（五张手牌葫芦概率 = 3,744 / C(52,5)）。

规则卡组

Sum Rule（不交可加）· Complement Rule（Pr[Ā] = 1−Pr[A]）· Difference Rule · Inclusion-Exclusion（容斥原样搬来）· Union Bound（17.8：Pr[E₁∪⋯∪Eₙ] ≤ ΣPr[Eₙ]）· Monotonicity。Union Bound 是算法分析里最常用的上界：飞船 n 个关键部件各自失效概率 pᵢ，"至少一个失效"的概率 ≤ Σpᵢ——宁要粗糙的上界，不要算不出的精确值。

17.5.4

无限概率空间：先手到底占多少便宜？

Infinite Probability Spaces

两人轮流掷公平硬币，先掷出正面者胜。样本空间无限：{TʰH}。先手在第 1, 3, 5, … 步获胜，概率 1/2 + 1/8 + 1/32 + ⋯ = 几何级数收口：

Pr[先手胜] = ½ · Σ (1/4)ⁿ = ½ · 1/(1−¼) = 2/3　　后手 1/3，和恰好为 1

树图里那条"永远掷出反面"的无限路径没有对应 outcome——概率 0 的事件不必放进模型，加了也无害（ωforever 的讨论）。上一章的几何级数 1/(1−x) 在这里领了第一份工资。

Easter Eggs & Problems
Marilyn 被骂了整整一年（17.2 开场）

1990 年 Parade 杂志专栏作家 Marilyn vos Savant 答"换门 2/3"，收到上万封抗议信，近千名博士署名反对（"你就是那只山羊的数学水平！"）。四步法树下无话可说：那些概率 1/9 的分支（主持人被迫开门）才是被直觉吃掉的部分。原信人 Craig Whitaker 的问题其实有歧义——若主持人不被要求开门，结论随规则改变（17.2.5）。

四门版蒙提霍尔（习题 17.5）

4 扇门、开 1 扇无奖门、可换到剩下两扇未开、未选门之一（等概率选）：坚持者 Stu 赢 1/4；换门者 Zelda 赢 3/8；而"总是换到最早那扇门"的 Mergatroid 还能算出精确胜率。门越多，坚持者越惨—— doors→∞ 时坚持胜率 → 0。

HHT 与 TTH 谁先出现？（习题 17.12）

反复掷公平硬币直到 HHT 或 TTH 出现——两个模式"看起来对称"，胜率却不是 1/2:1/2。模式匹配竞争是概率空间设计（什么叫一次"试验"？）的绝佳反例，Penney's game 的入门款。
