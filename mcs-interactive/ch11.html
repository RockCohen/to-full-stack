11.1

路由与路由问题

Routing

一个通信网络有 N 个输入端和 N 个输出端（N 取 2 的幂），中间是一堆小交换机。谁去谁家由一个置换 π 规定：输入 i 的包要送到输出 π(i)。路由就是解决这个 π 的一组路径。最朴素的网络是完全二叉树网：树中任意两点路径唯一，输入 1 到输出 3 的路线清晰唯一。

但树网有个致命伤：根交换机是瓶颈——任何跨子树的通信都要过它。最坏置换 π(i) ::= N−1−i 下，每个包都得路过根：根的拥塞 = N，网络整体报废。这逼出了三个度量：直径（最坏延迟）、开关数（成本）、拥塞（最坏负载）。

11.3.1

二维阵列：花直径换不堵

The 2-D Array

阵列把 N 个输入排成一列、N 个输出排成一行，中间 N² 个 2×2 开关。直径涨到 2N（差 1000 输入的树网 22 步 vs 阵列 2000 步），换来定理 11.3.1：拥塞恰好为 2。证明的两半都能"画"出来：上界——每包先右走到自己的列再下走，行 i 的开关最多只见 2 个包；下界——π(0)=0、π(N−1)=N−1 时左下角开关必被 2 个包穿过。

11.3.2

蝶形网：递归数据类型的胜利

The Butterfly

蝶形网是递归定义的（第 7 章语法再就业）：F₁ 是 2 输入 2 输出的交叉开关；Fₙ₊₁ 把两份 Fₙ 竖排，新输入 i 与 2ⁿ+i 各连到同一个第 i 个输入开关。开关数 N(logN+1)、直径 logN+2，拥塞约 √N——树与阵列的折中。每个输入到每个输出路径唯一（递归路由），习题 11.8 证明拥塞恰为 √N（N 偶次幂）：第 i 列每个开关恰有 2ⁱ 条入径与 2^(logN−i) 条出径。

11.3

网络设计四强与 Beneš 圣杯

Network Designs

2-D 阵列把拥塞压到 2（定理 11.3.1：先横后竖走，每个交换机至多经手 2 个包）——代价是 N² 个开关。Butterfly 网递归生长（Fₙ₊₁ = 两个 Fₙ + 新输入列），路由唯一、直径 log N + 2、拥塞 ≈ √N。Beneš 网则是把两个 butterfly 背靠背缝起来——开关和直径翻倍，换来 拥塞 = 1：任何置换都有"每条边至多一个包"的完美路由。Holy Grail 到手！

证明是归纳 + 一个漂亮的 2-着色：把"包 i 和包 j 不能走同一子网"记成约束图的边——约束图每个顶点至多 2 条边（一条来自输入约束、一条来自输出约束），两条边分属两组 ⇒ 每圈偶长 ⇒ 可 2-着色（引理 11.3.3）。红包走上子网、蓝包走下子网，归纳完成。
