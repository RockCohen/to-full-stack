20.1

马尔可夫定理：只用均值能说什么

Markov's Theorem
定理 20.1.1 · Markov

R 非负时：Pr[R ≥ x] ≤ Ex[R]/x。推论 20.1.2：Pr[R ≥ c·Ex[R]] ≤ 1/c。IQ 均值 100 → 至多 1/3 的人 IQ≥300。粗糙？当然——但 19 章的帽子问题（Ex[G]=1，Pr[G≥x]≤1/x）和中餐开胃菜问题（Pr[全对]≤1/n）都靠它一击命中。

让它变锋利的技巧：平移。已知 IQ 下界 100，令 T = R − 100（非负，均值 50），则 Pr[R>200] = Pr[T>100] ≤ 50/100 = 1/2——从 3/4 磨到 1/2。同类技巧套上平方就升级成切比雪夫。

互动 ①

🔍 IQ 侦探：三条界围捕一条正态尾巴

真实概率（正态 μ=100 σ=15） Markov 上界 100/x 平移 Markov（下界100） Chebyshev 15²/(x−100)²
x=300：Markov 只给 1/3，Chebyshev 磨到 1/178 ≈ 0.56%——信息每多一条（σ），界就紧一分。
20.2

切比雪夫：方差登场

Chebyshev's Theorem
定义 20.2.2 / 定理 20.2.3 · Chebyshev

Var[R] := Ex[(R − Ex[R])²]（均方偏差）；Pr[|R − Ex[R]| ≥ x] ≤ Var[R]/x²。用 σ = √Var（标准差，与 R 同单位）重写：Pr[|R−μ| ≥ cσ] ≤ 1/c²（推论 20.2.6）。

书中名场面：Game A（2/3 概率赢 $2、1/3 输 $1）与 Game B（2/3 赢 $1002、1/3 输 $2001）期望都是 $1——但 Var[A]=2，Var[B]=2,004,002。十局 A 最坏也就小输；十局 B 理论上能亏两万多。期望说"平均赚多少"，方差说"离均值有多疯"。

互动 ②

🎰 方差对比器：Game A vs Game B

期望恒为 $1（2/3 · W − 1/3 · (W−1) = (2W − W + 1)/3 = (W+1)/3 …等等，书里 Game B 输 $2001 恰好配平 $1——滑动验证）。σ 才是风险计。
20.3

方差的性质

Properties of Variance
规则全家桶

Var[R] = Ex[R²] − Ex²[R]（引理 20.3.1）· Bernoulli：Var = p(1−p) · 几何分布（每步失效概率 p）：Var = (1−p)/p² · Var[aR+b] = a²Var[R]（平移不动、缩放平方）· 独立可加：Var[R+S] = Var[R]+Var[S]——只需 pairwise 独立（定理 20.3.8）；R=S 反例：Var[2R] = 4Var[R] ≠ 2Var[R]。二项分布 Var = np(1−p)。

20.4

随机采样：该问多少人？

Estimation by Random Sampling

估计支持率 p：抽 n 人（有放回），样本占比 Sₙ/n。想要 ±0.04、95% 置信。Var[Sₙ/n] ≤ 1/(4n)（p(1−p) 在 p=1/2 最大），切比雪夫一压：

n ≥ 156.25/(0.04² · 5%) ⟹ n ≥ 3,125

推论 20.4.2（弱大数定律）：pairwise 独立、同均值有限方差 → 样本均值依概率收敛到 μ。选民总数从头到尾没出现过——3000 人永远够，不管总人口一万还是十亿。

20.5

置信的语言：别把 p 说成随机

Confidence in an Estimation
False Claim（书原话：but sloppy）

"1250/3125 的样本支持 Brown，所以『p > 1/3 的概率是 95%』"——错。p 是一个固定的真值，未知 ≠ 随机。正确的说法："我们的估计程序有 95% 的概率产出 ±0.04 内的结果"；民调员的话术："在 95% 置信水平下，支持率为 1250/3125 ± 0.04"——置信水平是对程序的评价，不是对 p 的赋概率。要么区间对了，要么发生了 1/20 的小概率事件。

20.6

Chernoff 界：把尾部打成指数级

The Chernoff Bound

均值和方差都知道了，切比雪夫就是天花板。但如果随机变量是一堆独立小变量之和（每个取值 ∈[0,1]），还有一把锤子——Chernoff 界（定理 20.6.1）：

Pr[T ≥ c·Ex[T]] ≤ e^(−β(c)·Ex[T])，β(c) := c·ln c − c + 1

指数 vs 多项式：Markov 给 1/c、切比雪夫给 1/c²、Chernoff 给 e^(−Θ(Ex[T]))。1000 次掷币正面超均值 20%（c=1.2，β=0.0187）：概率 < 1/10,000；超 30%（β=0.041）：1/10 亿；一百万枚硬币：e^(−9392)，"不可想象的小"。应用：Pick-4 彩票 1000 万玩家翻车概率 e^(−386)；Fussbook（虚构社交站）负载均衡——24000 帖、每帖平均 ¼ 秒、600 秒窗口：

Pr[某台超载] ≤ m·e^(−β(m/10)·6000/m)：m=11 → 0.78　m=12 → 0.0001　m=13 → 0.000000076

20.6.8Murphy 定律：能出错的，多半真会出错

反向使用：一堆独立事件，若期望发生件数 Ex[T] 很大，则 Pr[T = 0] ≤ e^(−Ex[T])。期望 10 件事发生 → 至少一件的概率 ≥ 1 − e⁻¹⁰ > 99.995%。10 万张 Pick-4 彩票"无人中奖"概率 < 1/22000——"巧合"、"奇迹"之所以出现，是因为可能的怪事实在太多，总概率加起来早就爆表了。

20.7Really Great Expectations：期望 ∞ 的"必胜"赌局

掷公平硬币直到出现正面，记下你连续反面的长度 k；然后不断重掷，直到掷出比 k 更长的反面连击才停——你必然会赢（概率 1），我每轮失败收你 1 分钱，赢了随便我付。听着像送钱？重试次数的期望 = 2^(k+1)（均故障时间），无条件期望 = Σ 1 = ∞。任何随机变量"等到出现更大值"的期望等待时间都是无限的——有限的奖金永远配不平无限的等待。

中餐开胃菜：Markov 的高光时刻（20.1.1）

n 人围坐转盘分冷盘，每人拿到自己原来那份的概率精确 = 1/n；马尔可夫只用了 Ex[R]=1 就给出 Pr[R≥n] ≤ 1/n——粗糙的界偶尔精确命中。而帽子问题真值 1/n! 时 Markov 仍只给 1/n：同一工具，时灵时不灵。
