12.1

度数与著名的平均度悖论

Vertex Degrees

简单图：边无方向、无自环、两点间至多一条边。握手引理（12.2.1）：所有顶点度数之和 = 边数的两倍——每次握手都贡献两只手。

它有个炸裂的应用。芝加哥大学、ABC News、美国卫生统计中心都调查过"美国人平均有过多少异性伴侣"，结论一致：男性比女性多 74%、233% 不等。原书用一行图论把这堆调查全部判死：把人当顶点、伴侣关系当边，男性度数和 = 女性度数和 = 边数，于是

Avg. deg in M = (|F| / |M|) · Avg. deg in F

两边平均度之比完全由人口性别比决定（美国 |F|/|M| ≈ 1.035，男性平均只可能多 3.5%）——与谁的"花心程度"毫无关系。亲手连边验证：

💘 平均度悖论实验台

4 位男士、4 位女士。点击两个点连一条边（再点取消）。左边的统计会实时审判任何"失调"的调查结论。

Σdeg(M) = 0 · 平均 = 0.00
Σdeg(F) = 0 · 平均 = 0.00
连接一些边试试——无论怎么连，两组平均度之比恒为 |F|/|M| = 1。
这就是为什么所有"男性平均伴侣数远超女性"的调查必然有系统误差：数学上，两组平均只可能由人口性别比决定。
12.3–4

常见图与同构侦探

Common Graphs & Isomorphism

明星图全家福：完全图 Kₙ（两两有边，n(n−1)/2 条边）、空图、线图 Lₙ、圈图 Cₙ。同构（isomorphism，Definition 12.4.1）则是"换个标签还是同一张图"的严格说法——一个保持边的双射 f：⟨u—v⟩ ∈ E(G) ⟺ ⟨f(u)—f(v)⟩ ∈ E(H)。同构保持度数、连通性、圈长等一切图性质；反过来，找到一个被保持的性质（比如度序列）不成立就证明了两图不同构。顺带：判断两图是否同构至今没有已知的多项式算法——这个"难"还支撑着一类加密协议。

12.7–9

圈、割边与树

Walks, Cut Edges & Trees

简单图里的 walk/path/cycle 与有向图版本几乎一样，只是箭头换成无向边、长度 2 的来回不算圈（Definition 12.7.1）。圈是子图（12.7.2）：没有起点、没有方向，bcdehb 和 dehbc 是同一个圈。连通性（12.8）：任意两点间有 path 则图连通；极大连通块叫连通分量。定理 12.8.3 的三等价：有奇圈 ⟺ 非 2-着色 ⟺ 有奇长闭合 walk。边还能论"结实程度"：割边（cut edge）= 拔掉就断的边，引理 12.8.6 一句话——割边 ⟺ 不在任何圈上；Kₙ 是 (n−1)-连通的，每个圈都 2-连通。

12.9 登场的树（连通无圈图）是计算机科学里最重要的图：定理 12.9.3 列了六条等价性质——连通子图仍是树、任意两点 path 唯一、加边生圈、每边都是割边、≥2 顶点必有 ≥2 叶、n 顶点恰 n−1 条边。每个连通图都含生成树（Theorem 12.9.6）；给边加上权重、想要总权最小的生成树（MST），Prim/Kruskal 的贪心就够（引理 12.9.11"最小灰边"）。原书 Figure 12.20(b) 那张加权图的最小生成树重 17——贪心拿到了。
