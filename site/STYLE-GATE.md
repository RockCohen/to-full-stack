# rockcohen.cc 风格门禁文档

> **版本 1.0 · 2026-09-12**
> 适用范围：rockcohen.cc 首页及所有下层页面（/maoxuan/、/mcs/、/paper/、/deepseek-harness/、/fullstack/、/tractatus-mindmap.html 及未来新项目）。
> 执行方式：新页面立项、旧页面改版、任何视觉相关 PR，必须先对照本文档「验收清单」逐条通过；与本文档冲突的实现一律打回。
> 配套文件：`theme.css`（设计令牌与共享组件的唯一实现）。**禁止复制粘贴改造**，一律 link 引入。

---

## 1. 设计原则（三条，按优先级）

1. **内容优先，装饰退让**。首屏不堆口号、不写长段自我介绍；用户三秒内必须能进入内容。
2. **浅色玻璃风**。通透、留白、柔和色晕；一切卡片用玻璃材质，不用实色死白。
3. **极度克制的色彩**。全站只有**一个强调色**（蓝 `--accent`），其余颜色只能出现在极光头图里。

## 2. 设计令牌（唯一取值来源）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` | `#23272e` | 主文字 |
| `--ink-2` | `#5d646d` | 次文字、描述 |
| `--ink-3` | `#9aa1ab` | 弱文字、时间戳、签名 |
| `--bg` | `#fafbfc` | 页面底色 |
| `--accent` | `#2f6fdb` | **唯一强调色**：链接、CTA、徽章、编号 |
| `--radius` | `20px` | 所有卡片圆角 |
| `--maxw` | `1080px` | 内容最大宽度 |
| `--glass` / `--glass-strong` | `rgba(255,255,255,.55)` / `.72` | 玻璃卡两档不透明度 |
| `--line` | `rgba(35,39,46,.08)` | 分割线、描边 |

字体：正文 PingFang SC / 系统栈；宋体（Songti SC）**只**用于品牌签名（座右铭）与具仪式感的标题。

## 3. 全站统一组件

### 3.1 品牌导航条
- 左侧：`cohen · rockcohen.cc │ 张帆济川，凿井及泉`（座右铭宋体 13px、`--ink-3`、细分隔线）
- 右侧：分区锚点 + GitHub 胶囊按钮
- 吸顶 + 毛玻璃（`blur(20px) saturate(1.5)`）
- **下层页面必须保留同一品牌条**，可删减锚点，不可改品牌区结构

### 3.2 玻璃卡（`.glass`）
- 配方：`background: var(--glass)` + `backdrop-filter: blur(20px) saturate(1.5)` + `1px solid var(--glass-border)` + 统一投影 `--shadow-glass`
- 悬停：上浮 `translateY(-3px)` + 不透明度升到 `--glass-strong`
- 禁止自造阴影参数、禁止纯色实卡

### 3.3 极光头图（`.aurora`）——**所有卡片头图 / 页面 hero 的唯一指定风格**
- 配方：五层径向渐变色晕（淡蓝/薰衣草/蜜桃/天青/白）+ `blur(28px)`，亮色相融，见 `theme.css`
- 标题：深色粗体居中（`#20242f` / 800），副标题 12px 灰色字距拉开
- 同一配方可用 `.h2`–`.h6` 做 ±30°~90° 色相偏移区分卡片，**禁止另调饱和度/明度**
- 卡片头图高度 172px，页面 hero 可加高但配方不变

### 3.4 状态徽章（三档，禁止第四色）
| 徽章 | 类名 | 使用场景 |
|---|---|---|
| 蓝底白字 NEW | `.badge-new` | 仅上线 30 天内的新项目，全站同时最多 1 个 |
| 浅蓝「持续更新/在线可学」 | `.badge-live` | 活跃更新中 |
| 灰色「已上线 N 章 / PWA 等属性」 | `.badge-info` | 状态或属性说明 |
- 每张卡片右上角标注 `更新于 YYYY-MM-DD` 或 `已完结`

### 3.5 分区头
- `编号胶囊（.sec-num）+ 分区名（24px 700）+ 一句副标题 + 延伸细线`

## 4. 页面结构模板

```
导航条（品牌条）
└─ Hero：极光头图（下层页面）或直接进内容（首页）
└─ 内容区：玻璃卡网格（桌面两列，移动单列）
└─ 收尾面板（在路上 / 关于，可选）
└─ 页脚：© 年份 cohen · 引用皆可回原文 · 数据皆可复现 · GitHub
```

首页首屏特别规定：**只保留 导航条 + 三支柱入口卡**。口号、长段介绍、更新列表一律不允许进入首屏（2026-09 改版结论）。

## 5. 门禁红线（违反即打回）

1. ❌ 禁止低饱和"泥巴色"色块——任何渐变色块必须亮色相融（v1 pastel 教训）
2. ❌ 禁止多主题色并列（赭/绿/蓝分区色标已被否决），全站只有 `--accent` 一个强调色
3. ❌ 禁止深色截图与浅色截图混排做头图——头图统一极光风
4. ❌ 禁止"截图卡 + 文字卡"双卡重复同一项目信息——一项目一张卡
5. ❌ 禁止全量挂 NEW 徽章——按 3.4 状态体系执行
6. ❌ 禁止首屏堆口号/座右铭大卡/长段介绍——座右铭只在品牌条
7. ❌ 禁止越过 `theme.css` 自造令牌值（圆角、阴影、蓝色、玻璃参数）
8. ❌ 禁止编号 01/02/03 暗示阅读顺序——三支柱是并列关系，编号仅作锚点标识

## 6. 下层页面统一要求

1. `<link>` 引入共享 `theme.css`，删除页面内与令牌冲突的本地样式
2. 页面 hero 改为极光风（`.aurora`），标题深色粗体居中；允许保留项目专属装饰，但底必须是极光配方
3. 导航换为统一品牌条（3.1），保留回主站链接
4. 页面内卡片、徽章、按钮改用 .glass / .badge 体系
5. 深色界面（如逻辑哲学论导图）属内容区豁免——**内容区可以保持功能所需的任何配色，门禁只约束框架层**（导航、hero、卡片、页脚）

## 7. 验收清单（上线前逐条打勾）

- [ ] 引入了 `theme.css`，无本地复制的令牌值
- [ ] 品牌导航条结构与主站一致，座右铭在正确位置
- [ ] 全页只有一个强调色 `--accent`
- [ ] 所有卡片为玻璃材质，投影用统一配方
- [ ] 头图/hero 为极光配方，无泥巴色、无混杂截图
- [ ] 徽章不超过三档，NEW 全站唯一
- [ ] 首屏无口号堆砌，三秒内可达内容
- [ ] 移动端（≤820px）网格正确降为单列，无横向溢出
- [ ] 页脚含"引用皆可回原文 · 数据皆可复现"

## 8. 变更管理

- 本文档与 `theme.css` 同步变更，版本号递增，变更记录在文末追加
- 任何"这次特殊"的豁免必须写入本文档第 5/6 条，否则视为违规
